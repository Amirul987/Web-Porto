# ✨ About

A modern and immersive **3D Developer Portfolio Website** built using **React**, **TypeScript**, **Three.js**, **GSAP**, and **WebGL**.

This portfolio is designed to deliver a premium user experience through smooth animations, interactive 3D elements, and a clean responsive interface.

Whether you're a frontend developer, backend engineer, full-stack programmer, or creative developer, this template provides an elegant foundation to showcase your work.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

Go to project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
